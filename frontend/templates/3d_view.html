Reconstruction Pipeline

RoadGuard AI uses a real photogrammetry pipeline. The viewer displays reconstruction output generated by COLMAP and does not generate a synthetic road when reconstruction data is unavailable.

1. Image Input

Road imagery is supplied to the photogrammetry pipeline.

2. COLMAP SfM

COLMAP performs feature extraction, image matching, camera estimation, and sparse reconstruction.

3. Dense Reconstruction

Dense reconstruction is generated when the required COLMAP processing succeeds.

4. 3D Visualization

Three.js displays the actual reconstruction produced by the backend.

Reconstruction Status

NOT_STARTED

COLMAP reconstruction has not started for this report.

FAILED

The reconstruction pipeline failed. No fake 3D model is displayed.

SPARSE_ONLY

COLMAP produced a sparse SfM model, but a dense reconstruction or mesh is not available.

DENSE_POINT_CLOUD

A real dense point cloud is available for visualization.

MESH_AVAILABLE
